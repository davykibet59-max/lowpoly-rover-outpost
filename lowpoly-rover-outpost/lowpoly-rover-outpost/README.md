# Low-Poly Rover Outpost

A **3D digital media portfolio project** focused on stylized game-ready asset creation for Blender and Godot workflows.

## What is included

- low-poly OBJ models
- Blender scene generator script
- rendered preview images
- Godot integration notes

## Tools represented

- **Blender** for modeling, layout, lighting, and export
- **Godot** for downstream real-time asset integration
- optional paintover / texture polish in GIMP or Krita

## Assets

- rover
- outpost habitat module
- scene layout script
- preview renders for GitHub presentation
