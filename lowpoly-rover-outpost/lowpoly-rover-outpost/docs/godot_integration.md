# Godot Integration Notes

These assets are intended to be easy to import into Godot after export from Blender as `.glb`.

Recommended workflow:
1. Run or edit `blender/scene_generator.py` in Blender.
2. Export selected models as `.glb`.
3. Import into Godot.
4. Add collision shapes and simple material instances.
5. Build a turntable viewer or exploration scene for presentation.

This makes the project useful for both 3D asset creation and engine-ready portfolio presentation.
